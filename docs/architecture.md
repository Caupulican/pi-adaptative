# Architecture map

Generated by `node scripts/architecture-map.mjs` from the header comments of the modules listed
below, plus the directory summaries the script holds. Regenerate after adding, extracting or moving a
module; `--check` fails when this file is stale. The words used here are defined in
[vocabulary.md](vocabulary.md). The invariants these modules enforce are in `docs/doctrine.md`.

## Directories

| Directory | What it owns |
|---|---|
| `packages/coding-agent/src/kernel/` | Provider-neutral harness kernel: the agent loop, message and usage model, request budgeting and planning, compaction, session storage and reliability primitives. It imports nothing else from coding-agent (`scripts/check-kernel-layer.mjs`). |
| `packages/coding-agent/src/modes/` | Run modes for the coding agent. |
| `packages/ai/src/` | The provider-neutral model layer: the API and model registries and the generated model catalog, provider adapters under `providers/`, shared stream and validation utilities under `utils/`. |
| `packages/tui/src/` | The terminal UI toolkit: terminal and input handling, the editor, key bindings and kill ring, the renderer (`tui.ts`), and the component library under `components/`. |
