# Pinned dependency source inputs

These immutable npm source archives reproduce two locally branded Node-contract adapters.
Their SHA-512 integrity values match the former lockfile's `braces@3.0.3` and `node-forge@1.4.0`
entries. Original licenses and copyright notices remain in the generated adapters.

`node scripts/generate-dependency-forks.mjs --write` regenerates the adapters;
without `--write` it checks every generated byte and rejects unexpected files.
The authoritative changes and helper implementations are under `scripts/dependency-forks/`;
they remain inside the production clone scan. Generated third-party code is outside the authored
production roots and is independently gated by exact source/patch reproduction, not blanket ignores.

Advisories `GHSA-vfj7-8cjw-p6xm` and `GHSA-86w9-cpqp-85rv` remain part of provenance.
A clean npm audit after local package renaming is not proof of remediation: focused negative and
positive controls, actual consumer resolution, installed-source checks and reproduction establish it.
Only the Node main/lib contracts used by Pi are provided; unused upstream browser/Flash prebundles
are not published as hardened artifacts.
